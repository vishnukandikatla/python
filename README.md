# Python Practice

A collection of beginner Python notes and example programs, organized by topic. The files cover basic programming concepts and include both `.py` examples and text notes.

## Topics

- **Chapter 2 — Strings and conditions:** conditional statements and string exercises
- **Chapter 3 — Lists and tuples:** list operations, slicing, tuples, and practice programs
- **Chapter 4 — Dictionaries and sets:** dictionary and set concepts, methods, and examples
- **Chapter 5 — Loops:** `for` and `while` loops, patterns, and related programs
- **Chapter 6 — Functions:** defining and using functions
- **Chapter 7 — File input and output:** file handling and exception handling
- **Chapter 8 — OOP:** classes, constructors, inheritance, encapsulation, and methods
- **Predefined functions:** notes and examples

Some topic folders contain notes and images alongside Python programs. There is also a duplicate-looking `chapters 3 Lists& tuples` folder; it currently contains a separate palindrome example.

## Running a Python example

Install Python 3, open a terminal in this repository, and run a `.py` file by passing its path to Python. For example:

```bash
python "chapter 2 strings & conditions/condition.py"
```

On some systems, use `python3` instead of `python`.

## Repository contents

- Topic folders contain notes, sample input files, images, and practice programs.
- `pyindex.docx` is an index document.
- `timepass.py` is a standalone Python example.

These are learning exercises, so individual files may be incomplete or require edits before they run.
